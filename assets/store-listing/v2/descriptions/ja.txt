外国語の長い動画も、数分で理解。YouTube 動画の AI 要約、プレーヤー上の二言語字幕、動画内容への質問、字幕全文のセクション翻訳をひとつの拡張機能で。お好みの AI サービスを、ご自身の API キーで利用できます。

主な機能

【AI 動画要約】
長い動画をワンクリックで構造化された要点にまとめます。各項目にタイムスタンプがあり、クリックすると該当箇所へ移動します。生成中の内容はリアルタイムで表示されます。

【プレーヤーに二言語字幕】
YouTube プレーヤー上に原文と訳文を同時に表示し、再生に合わせて同期します。通常・シアター・全画面モードに対応。これから再生される字幕を先読みで翻訳し、シークしても新しい位置から続けます。字幕テキストは選択してコピーでき、原文と訳文の文字サイズは個別に調整できます。

【学習モード】
通常は原文だけを表示し、字幕にマウスを重ねたときだけ訳文を表示します。外国語の学習に最適です。訳文のみの表示にも切り替えられます。

【動画の内容を質問】
「この主張の根拠は？」「この話題はどこで出てくる？」のように質問できます。回答は動画の字幕だけを根拠にし、字幕にない内容はその旨を伝え、クリックで移動できる時刻を添えます。

【字幕全文の閲覧と翻訳】
サイドパネルで字幕全文を読み、タイムスタンプをクリックして移動できます。現在のセクションだけ、または全文を翻訳でき、原文と訳文はいつでも切り替えられます。

【カスタムプロンプト】
分野ごとにプロンプトを保存し、要約と字幕翻訳で専門用語の訳し方を統一できます。

【14 の出力言語】
日本語、英語、簡体字中国語、繁体字中国語、韓国語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語、ベトナム語、タイ語、インドネシア語。画面表示は日本語、英語、簡体字・繁体字中国語、韓国語に対応しています。

【ローカルキャッシュ】
要約と翻訳の結果を 7 日間ローカルに保存し、同じ動画を開き直しても API を再度使いません。

使い方

1. ツールバーの拡張機能アイコンをクリックし、AI サービスとモデルを選んで API キーを貼り付け、保存します。
2. 字幕のある YouTube 動画を開き、プレーヤー右上の「AI 要約・翻訳」ボタンをクリックします。
3. 二言語字幕は、プレーヤーの CC ボタンの横にある翻訳ボタンでオンにできます。

API キーを設定していなくても、字幕の原文は閲覧・コピーできます。

プライバシーと料金

• API キーはこのデバイスにのみ保存され、Chrome の同期には含まれません。
• 字幕とリクエストは HTTPS で、選択した AI サービスへ直接送信されます。開発者のサーバーを経由せず、開発者がデータを受け取ることはありません。
• 拡張機能は無料です。AI の利用料金は各サービスの料金体系に従って請求されます。
• オープンソースです。ソースコードとプライバシーポリシーは GitHub で公開しています。
