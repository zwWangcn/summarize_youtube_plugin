外語長影片，幾分鐘看懂。在 YouTube 上一鍵產生 AI 摘要、在播放器中顯示雙語字幕、針對影片內容提問，並逐段翻譯完整字幕。可串接多家主流 AI 服務商，使用你自己的 API Key。

主要功能

【AI 影片摘要】
一鍵把長影片整理成結構化重點，每條都附時間戳記，點擊即可跳到原片對應位置。產生過程即時顯示，不必等全部完成。

【播放器雙語字幕】
在 YouTube 播放器中同時顯示原文與譯文，隨播放同步，支援一般、劇院與全螢幕模式。會預先翻譯即將播放的內容，拖動進度條後從新位置繼續。字幕文字可直接選取複製，原文與譯文字級可分別調整。

【學習模式】
預設只顯示原文，滑鼠移到字幕上才顯示譯文，適合看外語影片學語言。也可以設定為只顯示譯文。

【針對影片內容提問】
看完摘要仍有疑問，可以直接提問，例如「某個觀點的依據是什麼」「某個主題在哪裡講到」。回答只依據影片字幕，字幕沒提到的內容會直接說明，並附上可點擊跳轉的時間點。

【完整字幕閱讀與翻譯】
在側邊面板閱讀完整字幕，點擊時間戳記跳轉。可以翻譯目前這一段，也可以翻譯全文，原文與譯文一鍵切換。

【自訂提示詞】
為特定領域儲存提示詞，統一專業術語的譯法，套用於摘要與字幕翻譯。

【14 種輸出語言】
簡體中文、繁體中文、英文、日文、韓文、西班牙文、法文、德文、義大利文、葡萄牙文、俄文、越南文、泰文、印尼文。介面支援簡體中文、繁體中文、英文、日文與韓文。

【本機快取】
摘要與翻譯結果在本機保存 7 天，再次開啟同一部影片不必重複請求，節省 API 用量。

使用方式

1. 安裝後點擊工具列中的擴充功能圖示，選擇 AI 服務商與模型，貼上對應的 API Key 並儲存。
2. 開啟有字幕的 YouTube 影片，點擊播放器右上角的「AI 總結與翻譯」按鈕。
3. 雙語字幕可透過播放器 CC 按鈕旁的翻譯按鈕開啟。

尚未設定 API Key 時仍可查看與複製字幕原文。

隱私與費用

• API Key 只保存在目前裝置，不會透過 Chrome 同步。
• 字幕與請求透過 HTTPS 直接傳送到你選擇的 AI 服務商，不經過開發者的伺服器，開發者也收不到你的任何資料。
• 擴充功能本身免費，AI 呼叫費用由你的服務商帳戶依其規則收取。
• 專案開源，原始碼與完整隱私說明請見 GitHub。
