외국어 긴 영상도 몇 분 만에 이해하세요. YouTube 영상 AI 요약, 플레이어 이중 자막, 영상 내용 질문, 전체 자막 구간 번역을 하나의 확장 프로그램으로 사용할 수 있습니다. 원하는 AI 서비스를 본인의 API 키로 이용합니다.

주요 기능

【AI 영상 요약】
긴 영상을 클릭 한 번으로 구조화된 핵심 내용으로 정리합니다. 항목마다 타임스탬프가 있어 클릭하면 해당 장면으로 이동합니다. 생성 중인 내용이 실시간으로 표시됩니다.

【플레이어 이중 자막】
YouTube 플레이어에 원문과 번역을 함께 표시하고 재생에 맞춰 동기화합니다. 기본, 극장, 전체 화면 모드를 지원합니다. 곧 재생될 자막을 미리 번역하고, 탐색하면 새 위치부터 이어서 번역합니다. 자막 텍스트를 선택해 복사할 수 있고 원문과 번역의 글자 크기를 따로 조절할 수 있습니다.

【학습 모드】
평소에는 원문만 보여 주고 자막에 마우스를 올렸을 때만 번역을 표시합니다. 외국어 공부에 알맞습니다. 번역만 표시하도록 설정할 수도 있습니다.

【영상 내용 질문하기】
"이 주장의 근거는?", "이 주제는 어디에서 나오나요?"처럼 질문할 수 있습니다. 답변은 영상 자막만을 근거로 하며, 자막에 없는 내용은 없다고 알려 주고 클릭해 이동할 수 있는 시간을 함께 제공합니다.

【전체 자막 읽기와 번역】
사이드 패널에서 전체 자막을 읽고 타임스탬프를 클릭해 이동할 수 있습니다. 현재 구간 또는 전체를 번역할 수 있으며 원문과 번역을 언제든 전환할 수 있습니다.

【사용자 지정 프롬프트】
분야별 프롬프트를 저장해 요약과 자막 번역에서 전문 용어 번역을 통일할 수 있습니다.

【14개 출력 언어】
한국어, 영어, 중국어(간체), 중국어(번체), 일본어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 러시아어, 베트남어, 태국어, 인도네시아어. 화면 언어는 한국어, 영어, 중국어(간체·번체), 일본어를 지원합니다.

【로컬 캐시】
요약과 번역 결과를 7일 동안 로컬에 저장하므로 같은 영상을 다시 열어도 API를 다시 사용하지 않습니다.

사용 방법

1. 도구 모음의 확장 프로그램 아이콘을 클릭하고 AI 서비스와 모델을 선택한 뒤 API 키를 붙여 넣고 저장합니다.
2. 자막이 있는 YouTube 영상을 열고 플레이어 오른쪽 위의 'AI 요약 및 번역' 버튼을 클릭합니다.
3. 이중 자막은 플레이어의 CC 버튼 옆 번역 버튼으로 켤 수 있습니다.

API 키를 설정하지 않아도 자막 원문을 보고 복사할 수 있습니다.

개인정보 보호와 비용

• API 키는 이 기기에만 저장되며 Chrome 동기화에 포함되지 않습니다.
• 자막과 요청은 HTTPS로 선택한 AI 서비스에 직접 전송됩니다. 개발자 서버를 거치지 않으며 개발자는 어떤 데이터도 받지 않습니다.
• 확장 프로그램은 무료입니다. AI 사용 요금은 각 서비스의 요금 정책에 따라 청구됩니다.
• 오픈 소스 프로젝트입니다. 소스 코드와 개인정보처리방침은 GitHub에서 확인할 수 있습니다.
