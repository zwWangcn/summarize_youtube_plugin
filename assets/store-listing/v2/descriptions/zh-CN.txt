外语长视频，几分钟看懂。在 YouTube 上一键生成 AI 总结、在播放器里显示双语字幕、针对视频内容追问，并逐段翻译完整字幕。可接入多家主流 AI 服务商，使用你自己的 API Key。

主要功能

【AI 视频总结】
一键把长视频整理成结构化要点，每条都带时间戳，点击即可跳转到原片对应位置。生成过程实时显示，不用等全部完成。

【播放器双语字幕】
在 YouTube 播放器里同时显示原文和译文，跟随播放同步，支持普通、影院和全屏模式。会提前翻译即将播放的内容，拖动进度条后从新位置继续。字幕文字可以直接选中复制，原文和译文字号可分别调整。

【学习模式】
默认只显示原文，鼠标移到字幕上才显示译文，适合看外语视频学语言。也可以设置为只显示译文。

【就视频内容追问】
看完总结还有疑问，可以直接提问，例如“某个观点的依据是什么”“某个话题在哪里讲到”。回答只依据视频字幕，字幕没有涉及的内容会直接说明，并附带可点击跳转的时间点。

【完整字幕阅读与翻译】
在侧边面板阅读完整字幕，点击时间戳跳转。可以翻译当前一段，也可以翻译全文，原文和译文一键切换。

【自定义提示词】
为特定领域保存提示词，统一专业术语的译法，应用于总结和字幕翻译。

【14 种输出语言】
简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、越南语、泰语、印尼语。界面支持简体中文、繁体中文、英语、日语和韩语。

【本地缓存】
总结和翻译结果在本地保存 7 天，再次打开同一视频无需重复请求，节省 API 用量。

使用方式

1. 安装后点击工具栏中的扩展图标，选择 AI 服务商和模型，粘贴对应的 API Key 并保存。
2. 打开带字幕的 YouTube 视频，点击播放器右上角的“AI 总结与翻译”按钮。
3. 双语字幕可通过播放器 CC 按钮旁的翻译按钮开启。

未配置 API Key 时仍可查看和复制字幕原文。

隐私与费用

• API Key 只保存在当前设备，不会通过 Chrome 同步。
• 字幕和请求通过 HTTPS 直接发送到你选择的 AI 服务商，不经过开发者的服务器，开发者也收不到你的任何数据。
• 扩展本身免费，AI 调用费用由你的服务商账户按其规则收取。
• 项目开源，源代码和完整隐私说明见 GitHub。
